# Unity Project Skeleton

Tato slozka obsahuje prazdny scaffold pro budouci `Police Simulator`.

Ucel:

- zafixovat adresarovou strukturu
- pripravit misto pro data, scene, UI a prefaby
- zatim nevkladat runtime kod, dokud nebude pripraveny skutecny projekt

Predpokladane umisteni:

```text
Assets/
  Art/
    Characters/
    Clothing/
    Environment/
    Vehicles/
  Data/
    Commands/
    Cases/
    Characters/
    Clothing/
    Interactions/
    Station/
    Traffic/
  Prefabs/
    Characters/
    Environment/
    Vehicles/
    UI/
  Scenes/
  Scripts/
    Actions/
    Cases/
    Commands/
    Core/
    Interactions/
    Station/
    Traffic/
    UI/
  UI/
```

Zatim je to jen kostra pro budouci preneseni do skutecneho `Unity` projektu.
